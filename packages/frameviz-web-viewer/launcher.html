FrameViz

Python / C++ 的本地三维可视化工具

0.4.0 · 试用版

从一个场景开始

安装配套的 Python SDK 后，运行以下示例。场景会显示在独立窗口中。

import frameviz as fv

viz = fv.open(title="My scene")
viz.add_box(color=(0.2, 0.7, 0.9))
try:
    viz.spin()
finally:
    viz.close()

连接与安装

服务地址

由 SDK 自动发现

保持 FrameViz 运行，Python 和 C++ SDK 会从当前用户的本地记录中发现服务，并使用会话凭据连接。

安装镜像中的 SDK 文件夹包含 Python 安装包和 C++ SDK。首次安装、模型加载和 Vue 嵌入说明见镜像内的《开始使用》。

仅供本机单用户使用。场景保存在当前会话中，退出后不保留。通过应用菜单退出 FrameViz。
