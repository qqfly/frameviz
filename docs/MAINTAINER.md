# Maintainer decisions

The first-party copyright holder is qqfly and the project license is MIT. Preserve the license and copyright statement in redistributed substantial copies, and preserve each third-party component's own notices. Synthetic datasets are generated under the same first-party license and do not include earlier model/point-cloud assets. The original project icon is restored at the maintainer's explicit request; its provenance, declared rights and hashes are recorded in artwork/icon-source.json.

The project and protocol version is 0.5.0, currently unreleased. The source tree contains no inherited `.git` history, remotes, hooks, or organization identities. Before creating a first public commit, explicitly select the intended public Git author name/email instead of inheriting a machine's unrelated global identity. The maintainer has authorized a new PRIVATE GitHub repository and a new independent source history. Original repository history is preserved separately. No public registry or public release publication is authorized.

The private repository is https://github.com/qqfly/frameviz. Public registry namespaces and a security contact are not configured. Signing identities and credentials are supplied locally; they must never be committed. The current installer target is Apple Silicon macOS. JavaScript SDK packages remain private to prevent accidental publication under unconfirmed names. These destinations must be selected before publication; no URLs or contact addresses are invented.

The source dependency inventory includes development and optional native dependencies. Some third-party components have MPL or alternative license declarations; this project's MIT license does not replace those terms. A public binary needs an inventory/notices set for its actual contents and linkage, not merely the source lockfile SBOM. The source archive contains only manifest-listed first-party source, the two declared vendored headers, their notices, and generated fixtures and the explicitly restored project icon.

Maintenance helpers (`pnpm clean` and `clean:*`) are inspection-only: they list known paths inside this source tree and never remove shared package stores, user WebKit caches, runtime data, environments, or evidence. Review contents and process use before manually removing regenerated build outputs. This replaces the earlier global cache cleanup behavior.
